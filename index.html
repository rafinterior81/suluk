Pedoman Murid
Adab & Akhlak Murid kepada Mursyid
1
Taat dan Patuh Tanpa Syarat
Melaksanakan perintah Mursyid dengan sepenuh hati, selama tidak bertentangan dengan syariat, tanpa mempertanyakan dan menolak.
2
Menjaga Rahasia Thariqah
Tidak membocorkan amalan khusus, isyarat batin, dan pengalaman suluk kepada yang bukan mahramnya.
3
Husnudzon kepada Mursyid
Selalu berprasangka baik terhadap setiap tindakan Mursyid, karena beliau melihat dengan cahaya yang tidak kita miliki.
4
Dawam (Istiqomah) dalam Amalan
Tidak meninggalkan wirid yang telah ditentukan Mursyid kecuali dalam kondisi darurat yang diizinkan.
5
Khidmat Lahir & Batin
Melayani Mursyid dan sesama murid dengan tulus ikhlas tanpa mengharap pujian, sebagai riyadhah penghancur ego.
6
Melaporkan Kasyaf & Mimpi
Setiap pengalaman batin (kasyaf, mimpi, kondisi spiritual) dilaporkan kepada Mursyid untuk di-tashih dan dibimbing.

Cara Publish Aplikasi SALIK
Aplikasi ini adalah file HTML tunggal yang bisa langsung di-publish. Pilih salah satu cara berikut:
1. Netlify Drop (Termudah)
Buka netlify.com/drop → seret file salik-v3.html ke halaman tersebut → URL langsung jadi dalam 30 detik. Gratis selamanya.
🔗 app.netlify.com/drop
2. GitHub Pages (Gratis)
Buat repo di GitHub → upload file → Settings → Pages → Deploy from branch. URL: username.github.io/repo
🔗 github.com/new
3. Vercel (Profesional)
vercel.com → New Project → Import atau drag & drop folder. CDN global, domain custom gratis, analytics built-in.
🔗 vercel.com/new
4. Jadikan Aplikasi (PWA)
Setelah online, buka di Chrome/Safari → Menu → "Tambahkan ke Layar Utama". Langsung menjadi ikon di HP seperti app native.
5. Hosting Berbayar (Domain Sendiri)
Upload ke Niagahoster/Hostinger → domain .com mulai 100rb/tahun. cPanel → File Manager → public_html → upload file.
